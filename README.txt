This is fully working website but simple one. For this project I have used HTML, CSS and basic concept of javascript. 
This project helped me apply the concepts we learned in class, such as user-centered design, visual hierarchy, 
consistency, grouping, discoverability, cognitive load, accessibility, and responsive design.
I designed the website for tourists who want to explore Nepal and learn about different destinations.
I used clear navigation, organized destination cards, readable text, and consistent colors to make the 
website easy to understand and use. I also added a search feature and a review form to improve user 
interaction and provide feedback. I used HTML to structure the pages, CSS to design the layout, and JavaScript to 
make some features interactive. I also used responsive design so the website works on both computers and mobile devices.

Overall, this project helped me understand how the interface design principles we studied in class can be applied to a real website.
